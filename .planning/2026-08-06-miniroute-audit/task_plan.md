# MiniRoute / MnemoAgent 重新审阅计划

## 目标

完整审阅 MnemoAgent 实际运行流程，判断 MiniRoute 当前字段是否对应真实系统决策，并给出适合的职责边界。

## 阶段

- [x] 审阅被动对话与上下文/记忆链路
- [x] 审阅工具注册、可见性、治理与任务规划链路
- [x] 审阅主动触达与后台自治链路
- [x] 对照 MiniRoute 字段、准确率和真实消费点
- [x] 形成结论、推荐字段和下一步方案

## 审阅结论

MiniRoute 当前不适合作为完整 Agent 路由器、工具授权器或风险裁决器。
最适合的定位是：被动消息的轻量场景分类器和策略建议器，先以 Shadow 方式观测，
再在低风险的提示词/上下文策略选择上试用。
